# ちゃぴこ競馬AI v5 — 過去3走自動取得版

## 新機能
地方競馬の「今日の開催」を読み込むと、各出走馬についてNAR公式の競走馬データベースを照合し、
「馬出走履歴」からレース日より前の直近3走を取得します。

取得する履歴:
- 日付
- 競馬場 / R / レース名
- 距離 / 芝ダート / 馬場
- 人気 / 着順
- タイム / 着差 / 上3F
- 馬体重
- 騎手
- 斤量

## 予想モデルへの反映
- 前走 / 2走前 / 3走前に実着順を入力
- 直近3走を 50% / 30% / 20% で近況指数化
- 同距離に近い過去走から距離評価を補正
- 同馬場の履歴があれば馬場評価を補正
- 履歴が取れない馬はv4同様に全成績指数で補完
- 取得失敗を0点扱いしない

## 仕組み
`api/nar-history.js`
1. NAR競走馬検索で馬名を検索
2. 生年・父名・母名で同名馬を照合
3. lineageLoginCodeを取得
4. NAR HorseMarkInfo（馬出走履歴）を取得
5. 対象レース日より前の最新3走を抽出
